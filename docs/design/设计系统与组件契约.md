# 此间 - 设计系统与组件契约

> [!IMPORTANT]
> 本文档定义了“此间”（NCU Book）的统一 UI 视觉规范、Lucide 与吉祥物矢量图标使用标准、设计令牌（Design Tokens）以及前端 UI 组件职责契约（Component Contracts）。
>
> 规范已与终版可交互原型（`原型图/此间原型-优化重构版.html`）及 `src/components` 架构完成 100% 深度核对与对齐。

## 1. 视觉基准与排版规范

已批准的视觉方向为**“编辑黑白 + 人文宋体 + 墨蓝点睛”**：纯白画布、墨黑主字、灰色层级、克制细边线、墨蓝交互高亮。通过中文排版、留白与内容秩序体现编辑气质，严禁使用暖灰纸色或大面积品牌彩度制造杂乱氛围。

```text
       界面画布：纯白 (#FFFFFF)
       文字主色：墨黑 (#111111 / #1A1A1A)
       次级层级：中灰 (#4B5563 / #64748B) / 细边线 (#E2E8F0 / #E5E7EB)
       墨蓝点睛：主品牌蓝 (#1F9CF0 / rgba(31, 156, 240, 0.08))
   极简语义色：红 (风险/危险警示 #EF4444) / 蓝 (提示指引 #3B82F6) / 灰 (常规引用)
 触控面积保证：≥ 44px * 44px
 悬浮主操作球：50px 纯圆形固定白底吉祥物球 (right: 18px; bottom: 22px; 绝不随页面滚动)
```

### 1.1 核心设计原则
1. **内容先于界面**：长文、地图、表格与叙事决定版面，不以固定卡片模板强行包裹正文。
2. **移动优先**：360、390、430px 是首要审查尺寸；桌面端仅约束最大阅读宽度（760px），不改变任务路径与触控动线。
3. **单一主操作**：每个页面只有一个视觉主操作。首页是提问，文章是阅读，搜索页是输入关键词。
4. **渐进显露工具**：页面树抽屉、搜索、AI 工具在需要时唤起，不得常驻占领正文空间。
5. **固定悬浮球与脱离滚动流**：右下角小家园吉祥物悬浮提问球物理固定在视口右下角（`position: absolute; right: 18px; bottom: 22px;`），独立于正文滚动容器，任何滚动均保持常驻。
6. **极简色调与可信**：色彩服务语义与层级；留白、排版和内容本身承担审美。触控目标默认不小于 44px。

### 1.2 排版与字体使用规范
- **字体角色**：
  - **宋体 / 人文衬线体 (`font-serif`)**：用于首页大标题（「校园里的事，在此问明白。」）、经典名言引用（「是什么曾经拯救过你，就用它来更好地拯救这个世界」）、目录板块标题与文章一级标题（`h1`），传递人文与严谨气质。
  - **系统无衬线黑体 (`font-sans`)**：承担全局顶栏导航、元信息、正文段落、表单、抽屉与按钮，确保在各尺寸屏幕上具备极致的高清可读性。
- **正文与字重**：手机正文默认使用 15px~16px，行高 1.7；不得使用细字重作为常规文本。
- **标题层级**：标题层级通过字号、字重和间距表达，不依赖大面积颜色或装饰线。

> [!CAUTION]
> **绝对禁止**：
> - 常驻双侧栏、桌面文档站压缩版、首页瀑布式卡片墙。
> - 未经定义的渐变、发光、虚假 AI 视觉元素。
> - 混用 emoji、不同图标库或不同线宽 SVG。
> - 悬浮吉祥物球跟随页面内容一起滚动或被正文遮挡。
> - 使用米白、泛黄或大面积浅灰作为页面画布。

## 2. 图标语义映射表 (Lucide React & 品牌吉祥物)

项目通用图标统一使用 **Lucide React** 图标库；品牌提问入口统一使用南大家园独立矢量 **正圆小家园吉祥物（Mascot）**。禁止使用其他图标库、emoji 或私有变形 SVG。
默认图标尺寸：18px~20px；悬浮主操作球为 50px（内嵌 34px 吉祥物矢量）。所有图标按钮必须包含文字可见标签或 `aria-label`，触控区域保持 $\ge 44\text{px}$。

| 语义 | 图标定义 | 作用位置与规范 |
|---|---|---|
| 返回上级 / 首页 | Lucide `ArrowLeft` | 文档页左上角（20px，带 -8px 负边距保持 44px 热区）/ 从来源返回 AI 答案 |
| 打开板块/全局目录 | Lucide `Menu` | 首页右上角 / 文档页右上角（18px，位于搜索图标左侧） |
| 关键词搜索 | Lucide `Search` | 首页顶栏右上角 / 文档页右上角 / 搜索框内部 |
| 小家园吉祥物 (提问) | 品牌矢量正圆 Mascot | 首页搜索框右侧提问触发器 (20px) / 右下角 50px 纯圆固定悬浮球 (34px) |
| 发送问题 | Lucide `ArrowUp` / `Send` | AI 提问输入框提交按钮（黑色圆底白箭头） |
| 关闭抽屉/弹层 | Lucide `X` | 目录抽屉、搜索全屏、AI 问答底抽关闭按钮 |
| 展开下级页面 | Lucide `ChevronRight` | 目录树折叠展开、上下篇切换卡片右侧箭头 |
| 收起层级 | Lucide `ChevronDown` | 目录树、折叠内容展开收起 |
| 外部链接 | Lucide `ArrowUpRight` | 标示站外外链 |
| 复制 / 链接 | Lucide `Link` / `Copy` | 分享、复制链接与黄页电话一键拨号复制 |
| 文件附件 | Lucide `Paperclip` | 文档附件 |
| 信息提示 | Lucide `Info` | 中性说明与 Notion 提示框 |
| 风险提醒 | Lucide `TriangleAlert` | 需核实或风险警示框 |

## 3. 前端 UI 组件职责契约 (Component Contracts)

> 分五组：基础原语（`src/components/primitives/`）、问答（`ask/`）、搜索（`search/`）、富内容渲染（`article/`）、管理后台（`admin/`）。页面组合（首页/板块页/文档页/搜索页）是 `app/` 下的 RSC 组合层。

### 3.1 基础原语

| 组件名称 | 职责定位 | 必须行为 | 严禁行为 |
|---|---|---|---|
| `AppHeader` | 提供当前页面的最少导航 | **文档页**：左返回（`←`）、中板块进度+标题、右目录（`☰`）+搜索（`Q`）；**首页**：左品牌、右目录+搜索；保持 44px 触控区 | 常驻占用多行、塞入无关入口、左上角误用三横线 |
| `PageTreeDrawer` | 浏览当前板块或全站目录 | 焦点锁定、关闭后返回触发元素、支持上级返回；双层树（板块 -> 篇目）；懒加载（next/dynamic） | 作为全站无限常驻侧栏、遮住正文后无法退出 |
| `Skeleton` | 各路由 loading 骨架屏共享原语 | 与所替代页面结构同形、animate-pulse、aria-hidden | 各 loading 页私造骨架结构 |
| `StatusPage` | 错误页/404 共享视觉原语 | 图标 + 标题 + 描述 + 单一主操作按钮 | 各错误页私造布局 |

### 3.2 AI 问答

| 组件名称 | 职责定位 | 必须行为 | 严禁行为 |
|---|---|---|---|
| `AskProvider` / `useAsk` | 全站提问宿主（`ask/provider.tsx`） | 区分页面上下文、持久化草稿/回答、恢复返回状态 | 与关键词搜索复用提交路径 |
| `QuestionForm` | 首页胶囊提问搜索入口 | 白底浅灰边框、问问小家园提示文案、右侧吉祥物图标触发器 | 导航到外部问答或人格化迎宾 |
| `DocumentAskEntry` | 文档页滚动段落上下文捕获 | IntersectionObserver 跟踪当前标题锚点，驱动 FAB 上下文感知 | 常驻监听全站页面 |
| `FloatingAskButton` | 打开页面上下文 AI 悬浮球 | **50px 纯圆形固定球**；物理挂载于手机视口容器（`right: 18px; bottom: 22px;`）；脱离正文滚动流；携带当前文章上下文 | 随正文滚动移位、变形拉伸、常驻文字标签遮挡视口 |
| `AskSheet` | 承载 AI 问答弹层 | 底部滑出 Bottom Sheet；显示当前上下文、出处角标（`[1]`）、段落高亮跳转与返回回答；懒加载 | 人格化寒暄、隐藏不确定性 |
| `AskInputBar` | 提问输入条共享组件 | 受控输入、提交态、ArrowUp 圆钮、44px 触控区 | 两处各自私造输入条 |

### 3.3 关键词搜索

| 组件名称 | 职责定位 | 必须行为 | 严禁行为 |
|---|---|---|---|
| `SearchExperience`（搜索框与结果容器） | 输入关键词并展示命中 | 全屏滑出视图；顶部快捷词 Chips；清除、加载、空状态；客户端全量 31 篇索引内存匹配优先、API 降级 | 混用关键词搜索与 AI 问答结果 |
| `SearchResultItem` | 展示全文检索命中 | 标题、所属板块、匹配段落文字摘录、稳定锚点链接、**关键词加粗高亮 (`<mark class="search-highlight">`)** | 生成摘要答案或加入无关推荐 |

### 3.4 富内容渲染

| 组件名称 | 职责定位 | 必须行为 | 严禁行为 |
|---|---|---|---|
| `ArticleRenderer` | 渲染站内富文档 | 保留块树、锚点、表格、多栏和附件语义；文末提供上下篇切换卡片与有帮助/没帮助反馈条 | 将长文改造成卡片流或丢弃结构 |
| `RichText` | 保留发布富文本语义 | 支持批准的 annotations、站内 pageId 与外链；黄页电话点击拨号 Toast | 猜测未知标记或同时使用 href/pageId |
| `CalloutBlock` | 呈现提醒语义 | 严格支持 Notion 契约：`.notion-callout-red`（危险/红底）、`.notion-callout-blue`（指引/蓝底）、常规灰底 | 用作营销横幅或替代正文层级 |
| `QuoteBlock` | 呈现引用及其原始子块 | 保持引用语义容器内复用递归 renderer | 扁平化 children、改写为卡片 |
| `DividerBlock` | 保留正文分隔语义 | 使用既有边线令牌和正文间距，不进入搜索结果 | 添加标题、图标、卡片背景或装饰色 |
| `TableBlock` | 呈现表格 | 手机横向滚动、固定/清晰表头、可读内容 | 删除列、把数据改写为图形卡片 |
| `ColumnsBlock` | 呈现并列内容 | 宽屏并列、手机顺序堆叠 | 在窄屏保留不可读的双列 |
| `ImageBlock` | 渲染站内镜像图片 | 解析 Asset、展示 alt/caption、失败降级、声明尺寸防 CLS | 使用 Notion 临时 URL |
| `ListBlock` | 渲染列表 | 保留顺序、层级和 item 稳定锚点 | 拆成卡片或丢弃 children |
| `FileBlock` | 渲染附件 | 展示文件名、caption 与公开资源链接 | 静默隐藏失败附件 |
| `EmbedBlock` | 渲染允许的嵌入 | 仅支持 allowlist provider，失败时给外链 | 注入任意 iframe |
| `PageLinkBlock` | 渲染站内页面引用 | 通过 pageId 解析站内路由 | 将站内链接退化为 Notion 链接 |

### 3.5 管理后台

| 组件名称 | 职责定位 | 必须行为 | 严禁行为 |
|---|---|---|---|
| `SyncPanel` | Notion 一键同步与预检 | Dry-Run 开关、进度轮询、日志自动滚底、僵尸锁强解 | 跳过鉴权、静默吞错 |
| `VersionTimeline` | 内容版本历史与回滚 | 空记录时仅合成"当前指针"占位、一键回滚、发布后自动刷新 | 编造假版本数据 |
| `LogoutButton` | 管理员登出 | DELETE `/api/admin/auth` 后回登录页 | 无提交能力的坏死表单 |

### 3.6 页面组合契约（`app/` RSC 组合层）

| 页面 | 职责定位 | 必须行为 | 严禁行为 |
|---|---|---|---|
| 首页 `/` | 组合首页 RSC 页面 | 品牌顶栏 + 宋体大标题 + 名言引用 + 胶囊提问框 + 公告卡片 + 6 大板块 31 篇双列目录 + 完善手册 + 页脚致谢 | 瀑布式卡片墙抢占首屏、丢失双列目录 |
| 板块页 `/sections/[slug]` | 组合自由板块导读 RSC 页面 | 保留富内容并提供线性子页面入口 | 将板块固定成分类卡片模板 |
| 文档页 `/docs/[slug]` | 组合阅读器文档 RSC 页面 | 正文优先、顶部返回+进度标题+目录搜索、右下角 50px 固定吉祥物浮球 | 固定常驻双侧栏、悬浮球随正文滚动跑位 |
| 搜索页 `/search` | 组合关键词搜索结果 RSC 页面 | 仅呈现原文命中与锚点，命中关键词高亮 | 调用 AI 或生成摘要 |

## 4. 设计令牌数据源 (Tokens JSON)

所有组件样式必须引用 [docs/design/tokens.json](tokens.json) 中定义的语义令牌（含 accent/alert/pill/subtle 四条兼容性别名），严禁添加页面私有随意色值、字号与间距补丁。
