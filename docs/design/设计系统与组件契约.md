# 此间 - 设计系统与组件契约

> [!IMPORTANT]
> 本文档定义了“此间”（NCU Book）的统一 UI 视觉规范、Lucide 图标使用标准、设计令牌（Design Tokens）以及前端 UI 组件职责契约（Component Contracts）。
>
> 组件清单与 `src/components` 实际文件一一对应（2026-08-14 与重建后代码库核对修订）。

---

## 1. 视觉基准与排版规范

已批准的视觉方向为**“编辑黑白”**：纯白画布、黑墨文字、灰色层级、克制边线。通过中文排版、留白与内容秩序体现编辑气质，不使用暖灰纸色或品牌彩色制造氛围。

```text
       界面画布：纯白 (#FFFFFF)
       文字主色：墨黑 (#000000 / #111111)
       次级层级：中灰 / 细边线
   极简语义色：红 (风险) / 黄 (提示) / 绿 (成功)
 触控面积保证：≥ 44px * 44px
```

### 1.1 核心设计原则
1. **内容先于界面**：长文、地图、表格与叙事决定版面，不以固定卡片模板强行包裹正文。
2. **移动优先**：360、390、430px 是首要审查尺寸；桌面端仅扩展空间，不改变任务路径。
3. **单一主操作**：每个页面只有一个视觉主操作。首页是提问，文章是阅读，搜索页是输入关键词。
4. **渐进显露工具**：页面树抽屉、搜索、AI 工具在需要时唤起，不得常驻占领正文空间。
5. **极简色调与可信**：色彩服务语义与层级；留白、排版和内容本身承担审美。触控目标默认不小于 44px。

### 1.2 排版与字体使用规范
- **字体角色**：界面和正文仅使用 `tokens.json` 的 `fontFamily`。系统黑体承担导航、正文和操作；**宋体仅用于首页展示标题、板块标题和文章一级标题**，不进入按钮、标签或长篇正文。
- **正文与字重**：手机正文默认使用 `fontSize.body` 与 `lineHeight.body`；不得使用细字重作为常规文本。
- **标题层级**：标题层级通过字号、字重和间距表达，不依赖大面积颜色或装饰线。每页最多使用两类字体角色。

> [!CAUTION]
> **绝对禁止**：
> - 常驻双侧栏、桌面文档站压缩版、首页瀑布式卡片墙。
> - 未经定义的渐变、发光、虚假 AI 视觉元素。
> - 混用 emoji、不同图标库或不同线宽 SVG。
> - 使用米白、泛黄或大面积浅灰作为页面画布。

## 2. 图标语义映射表 (Lucide React)

项目统一使用 **Lucide React** 图标库。除品牌标志外，禁止使用其他图标库、emoji 或手写 SVG。
默认图标尺寸：20px；导航或悬浮主操作可使用 24px。图标按钮必须包含文字可见标签或 `aria-label`。

| 语义 | Lucide 图标 | 作用位置与规范 |
|---|---|---|
| 打开页面树 | `Menu` | 文档页左上 (20px/24px) |
| 返回上级 | `ArrowLeft` | 文档页左上 / 从来源返回 AI 答案 |
| 关键词搜索 | `Search` | 头部导航与搜索页 |
| 打开 AI 提问 | `Sparkles` | 右下角悬浮入口 |
| 发送问题 | `ArrowUp` | AI 输入框提交按钮 |
| 关闭抽屉/弹层 | `X` | 抽屉与弹层关闭 |
| 展开下级页面 | `ChevronRight` | 页面树折叠展开 |
| 收起层级 | `ChevronDown` | 页面树、折叠内容 |
| 外部链接 | `ArrowUpRight` | 标示站外外链 |
| 返回回答 | `ArrowLeft` | 从来源页返回回答 |
| 复制链接 | `Link` | 分享/复制链接 |
| 文件附件 | `Paperclip` | 文档附件 |
| 信息提示 | `Info` | 中性说明 |
| 风险提醒 | `TriangleAlert` | 需核实或风险说明 |

### 2.1 状态页与管理后台扩展图标清单

学生端主视图严格遵循上方核心图标表；异常状态页与管理后台（`/admin/*`）授权使用以下辅助与运维图标：

| 场景 | Lucide 图标 | 作用位置与说明 |
|---|---|---|
| 错误重试 | `RotateCcw` | 全局异常与路由错误页重试操作 |
| 页面未找到 | `FileQuestion` | 404 Not Found 缺省提示 |
| 板块目录 | `FolderTree` | 板块索引页与树形导航 |
| 搜索展开/收起 | `ChevronUp` | 搜索结果富文本段落折叠 |
| 异常报警 | `AlertCircle` | 表单校验与登录失败提示 |
| 运维操作 | `Play`, `RefreshCw`, `RotateCcw`, `Trash2` | 发布触发、重试、强制解锁 |
| 状态与度量 | `CheckCircle2`, `Clock`, `ShieldAlert`, `History`, `BarChart3`, `FlaskConical` | 同步日志状态、版本时间线、评测指标面板 |
| 管理工具 | `Terminal`, `TestTube`, `Copy`, `Check`, `Lock`, `LogOut`, `Filter`, `Send`, `ArrowRight`, `SlidersHorizontal`, `BookmarkPlus`, `Eye`, `Layers`, `HelpCircle`, `FileText` | 日志终端、QA 测试沙盒、参数调节、用例收藏与白盒探针视图、登录与鉴权状态 |

## 3. 前端 UI 组件职责契约 (Component Contracts)

> 分五组：基础原语（`src/components/primitives/`）、问答（`ask/`）、搜索（`search/`）、富内容渲染（`article/`）、管理后台（`admin/`）。页面组合（首页/板块页/文档页/搜索页）是 `app/` 下的 RSC 组合层，遵守 3.6 页面契约。

### 3.1 基础原语

| 组件名称 | 职责定位 | 必须行为 | 严禁行为 |
|---|---|---|---|
| `AppHeader` | 提供当前页面的最少导航 | 返回、页面树、关键词搜索；保持 44px 触控区 | 常驻占用多行、塞入无关入口 |
| `PageTreeDrawer` | 浏览当前板块页面树 | 焦点锁定、关闭后返回触发元素、支持上级返回；懒加载（next/dynamic） | 作为全站无限侧栏、遮住正文后无法退出 |
| `Skeleton` | 各路由 loading 骨架屏共享原语 | 与所替代页面结构同形、animate-pulse、aria-hidden | 各 loading 页私造骨架结构 |
| `StatusPage` | 错误页/404 共享视觉原语 | 图标 + 标题 + 描述 + 单一主操作按钮 | 各错误页私造布局 |

### 3.2 AI 问答

| 组件名称 | 职责定位 | 必须行为 | 严禁行为 |
|---|---|---|---|
| `AskProvider` / `useAsk` | 全站提问宿主（`ask/provider.tsx`） | 区分页面上下文、持久化草稿/回答、恢复返回状态 | 与关键词搜索复用提交路径 |
| `QuestionForm` | 首页发起 AI 提问 | 可见标签、提交状态、调用 `AskProvider` | 导航到 `/search` 或人格化迎宾 |
| `DocumentAskEntry` | 文档页滚动段落上下文捕获 | IntersectionObserver 跟踪当前标题锚点，驱动 FAB | 常驻监听全站页面 |
| `FloatingAskButton` | 打开页面上下文 AI | 携带 page 与 heading context；避开 safe area | 作常驻面板；遮挡正文控件或系统区域 |
| `AskSheet` | 承载 AI 问答弹层 | 显示当前上下文、来源、跳转与返回回答；懒加载（next/dynamic, ssr:false） | 人格化寒暄、隐藏不确定性 |
| `AskInputBar` | 提问输入条共享组件（首页表单与弹层追问复用） | 受控输入、提交态、ArrowUp 圆钮、44px 触控区 | 两处各自私造输入条 |

### 3.3 关键词搜索

| 组件名称 | 职责定位 | 必须行为 | 严禁行为 |
|---|---|---|---|
| `SearchExperience`（搜索框与结果容器） | 输入关键词并展示命中 | 清除、提交、加载、空状态与可见标签；客户端全量索引内存匹配优先、API 降级 | 混用关键词搜索与 AI 问答结果 |
| `SearchResultItem` | 展示全文检索命中 | 标题、板块、段落摘录、稳定锚点链接、命中高亮 | 生成摘要答案或加入无关推荐 |

### 3.4 富内容渲染

| 组件名称 | 职责定位 | 必须行为 | 严禁行为 |
|---|---|---|---|
| `ArticleRenderer` | 渲染站内富文档 | 保留块树、锚点、表格、多栏和附件语义 | 将长文改造成卡片流或丢弃结构 |
| `RichText` | 保留发布富文本语义 | 支持批准的 annotations、站内 pageId 与外链 | 猜测未知标记或同时使用 href/pageId |
| `CalloutBlock` | 呈现提醒语义 | 以低干扰视觉区分信息/提醒/风险 | 用作营销横幅或替代正文层级 |
| `QuoteBlock` | 呈现引用及其原始子块 | 保持引用语义容器内复用递归 renderer | 扁平化 children、改写为卡片 |
| `DividerBlock` | 保留正文分隔语义 | 使用既有边线令牌和正文间距，不进入搜索结果 | 添加标题、图标、卡片背景或装饰色 |
| `TableBlock` | 呈现表格 | 手机横向滚动、固定/清晰表头、可读内容 | 删除列、把数据改写为图形卡片 |
| `ColumnsBlock` | 呈现并列内容 | 宽屏并列、手机顺序堆叠 | 在窄屏保留不可读的双列 |
| `ImageBlock` | 渲染站内镜像图片 | 解析 Asset、展示 alt/caption、失败降级、声明尺寸防 CLS | 使用 Notion 临时 URL |
| `ListBlock` | 渲染列表 | 保留顺序、层级和 item 稳定锚点 | 拆成卡片或丢弃 children |
| `FileBlock` | 渲染附件 | 展示文件名、caption 与公开资源链接 | 静默隐藏失败附件 |
| `EmbedBlock` | 渲染允许的嵌入 | 仅支持 allowlist provider，失败时给外链 | 注入任意 iframe |
| `PageLinkBlock` | 渲染站内页面引用 | 通过 pageId 解析站内路由 | 将站内链接退化为 Notion 链接 |

### 3.5 管理后台

| 组件名称 | 职责定位 | 必须行为 | 严禁行为 |
|---|---|---|---|
| `SyncPanel` | Notion 一键同步与预检 | Dry-Run 开关、进度轮询、日志自动滚底、僵尸锁强解 | 跳过鉴权、静默吞错 |
| `VersionTimeline` | 内容版本历史与回滚 | 空记录时仅合成"当前指针"占位、一键回滚、发布后自动刷新 | 编造假版本数据 |
| `LogoutButton` | 管理员登出 | DELETE `/api/admin/auth` 后回登录页 | 无提交能力的坏死表单 |

### 3.6 页面组合契约（`app/` RSC 组合层，非独立组件文件）

| 页面 | 职责定位 | 必须行为 | 严禁行为 |
|---|---|---|---|
| 首页 `/` | 组合首页 RSC 页面 | 首屏提问优先、板块入口简洁清晰 | 瀑布式卡片墙抢占首屏 |
| 板块页 `/sections/[slug]` | 组合自由板块导读 RSC 页面 | 保留富内容并提供线性子页面入口 | 将板块固定成分类卡片模板 |
| 文档页 `/docs/[slug]` | 组合阅读器文档 RSC 页面 | 正文优先、工具按需唤起 | 固定双侧栏或重写正文 |
| 搜索页 `/search` | 组合关键词搜索结果 RSC 页面 | 仅呈现原文命中与锚点 | 调用 AI 或生成摘要 |

> 视觉审阅样张（360/390/430px）属设计评审流程产物，不作为生产组件存在。

## 4. 设计令牌数据源 (Tokens JSON)

所有组件样式必须引用 [docs/design/tokens.json](tokens.json) 中定义的语义令牌（含 accent/alert/pill/subtle 四条兼容性别名），严禁添加页面私有随意色值、字号与间距补丁。
