# 此间 - 生产部署与应急回滚手册

> [!IMPORTANT]
> 本文档定义了“此间”（NCU Book）学生端在腾讯云 EdgeOne / Vercel 生产环境下的部署演练、环境变量矩阵、限流策略及紧急回滚操作规范。

---

## 1. 交付与环境配置

- **应用定位**：仓库根目录为唯一学生端 Next.js 生产应用，部署采用 Node.js preset 及 npm lockfile。
- **环境隔离**：生产环境变量在 EdgeOne 控制台配置；`SUPABASE_SERVICE_ROLE_KEY` 与 `AI_PROVIDER_API_KEY` 严禁带有 `NEXT_PUBLIC_` 前缀。

### 1.1 环境变量矩阵

| 变量名 | 作用描述 | 推荐生产值 / 格式 | 必须/可选 |
|---|---|---|---|
| `SUPABASE_URL` | Supabase 项目 API 地址 | `https://your-project.supabase.co` | **必须** |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase 服务端 Role 秘钥 | 服务端私密 Key (必须带 server-only 隔离) | **必须** |
| `CRON_SECRET` | 定时任务秘钥 (用于防护 `/api/sync/lark`) | 强随机 Key (未配置时同步路由直接响应 503) | **必须** |
| `PUBLISHED_ASSETS_BUCKET` | 静态资源 Storage Bucket | `published_assets` | **必须** |
| `PUBLISHED_CONTENT_ENV` | 内容运行环境模式 | `production` | **必须** |
| `AI_ANSWER_MODE` | AI 回答模式 | `production` (本地评测/降级止血可配置为 `fixture`) | **必须** |
| `AI_PROVIDER_BASE_URL` | 大模型服务地址 | `https://api.deepseek.com` | **优点/推荐** |
| `AI_PROVIDER_API_KEY` | 大模型 API Key | DeepSeek 私密 Key | **必须** |
| `AI_CHAT_MODEL` | 聊天模型名称 | `deepseek-v4-flash` | **必须** |
| `AI_REQUEST_TIMEOUT_MS` | 请求超时时间 | `8000` | 可选 (默认 8000) |
| `AI_RATE_LIMIT_PER_MINUTE` | 每 IP 限流频次 | `10` | 可选 (默认 10) |

## 2. 部署与预发布演练流程 (Staging Drill)

1. **版本记号**：记录代码 Commit Hash、数据库构建 Timestamp 及执行人。
2. **干运行验证**：执行 `npm run publish:dry`，确认无未知 Block 失败或断链。
3. **全套自动化测试**：
   - 运行代码规范检查：`npm run lint`
   - 运行类型检查：`npm run typecheck`
   - 运行单元测试：`npm test` (43 个测试套件、172 项断言)
   - 运行生产构建：`npm run build`
4. **发布确认**：静态 SSG 页面生成无误后切线上线。

## 3. 限流与安全策略

- `/api/ask` 与 `/api/search` 接口在 EdgeOne / WAF 平台设置规则：`10 requests / minute / client IP`。
- `/api/ask` 应用层限流经 Supabase `rate_limit_buckets` 表与 `consume_ask_rate_limit` 原子 RPC 共享计数账本，多实例/多节点部署下阈值全局生效，超出阈值响应 HTTP 429；账本仅存客户端 IP 的 SHA-256 不可逆哈希，过期窗口行随每次计数自动清理。首次启用前须在 Supabase 执行 `supabase/schema.sql` 中的限流表与 RPC 定义。
- Supabase 未配置时应用层自动回退进程内分钟窗口计数器（单实例语义，仅限本地开发）；EdgeOne / WAF 平台规则始终是第一道防线。
- 日志保留周期契约：运行日志 14 天、反馈关联数据 30 天。问答遥测以结构化 JSON 输出至 EdgeOne 运行日志，平台侧日志保留策略须配置为不低于 14 天；项目不落盘用户完整提问，未来引入反馈关联存储时须按 30 天窗口清理。
- 日志严禁记录用户完整提问、大模型 Token 原始输出或 API Key。

## 4. 紧急止血与回滚手册 (Emergency Rollback)

> [!CAUTION]
> **自动触发条件**：出现以下任何一项时必须立即触发止血或回滚：
> 1. 首页、板块或文档页主路径出现 5xx 报错或 404 页面失联。
> 2. Supabase 内容数据或资源 CDN 链路损坏。
> 3. 大模型服务端连续超时（p95 延迟超过 8 秒）或产生无依据事实。

```text
出现生产问题
    │
    ├─► 仅大模型问题/延迟超标 ──► 修改 AI_ANSWER_MODE=fixture 止血 (文档正常阅读，问答返回静态保底)
    │
    ├─► 代码部署导致溃败 ─────► 在 EdgeOne 控制台 Rollback 至上一成功产物
    │
    └─► 数据库同步数据损坏 ───► 复原 Supabase published_content_pointer 版本指针
```

### 4.1 回滚步骤
1. **降级 AI 止血**：若仅为 AI 大模型异常或超时，优先将 `AI_ANSWER_MODE` 修改为 `fixture`，可立即止血而不影响纯静态文档浏览。
2. **代码产物回滚**：在 EdgeOne 控制台将生产构建直接 Rollback 至上一个成功构建产物（Deployment Artifact）。
3. **数据库指针回滚**：若为 Notion 发布导致的数据问题，在 Supabase `published_content_pointer` 表中复原 `content_version` 指针至上一版本，刷新 ISR。

## 5. 生产冒烟与 B4–B6 性能基准 (Performance Benchmarks)

### 5.1 站点域名配置
生产部署必须配置 `SITE_URL` 环境变量为真实域名（如 `https://your-domain.example`），它驱动 sitemap、robots.txt 与 OG 分享卡片中的绝对链接。未配置时回退 `http://localhost:3000`，仅适用于本地开发。

### 5.2 部署后路由冒烟
在部署到 EdgeOne 生产节点后，运行路由冒烟探针（状态码 / TTFB / HTML 体积 / title / viewport）：
```bash
# 审计本地生产环境 (需先 npm run build && npm start)
npm run audit:routes -- --url http://localhost:3000

# 审计 EdgeOne 线上生产环境（替换为真实域名）
npm run audit:routes -- --url "$SITE_URL"
```

### 5.3 B4–B6 真实浏览器补测（必做）
冒烟探针不替代 Lighthouse。部署后必须用真实 Lighthouse 对 `/`、`/docs/<slug>`、`/search` 三条路由补测并存档结果：
```bash
npx lighthouse "$SITE_URL" --form-factor=mobile --throttling-method=simulate --output=html
```
达标线：LCP ≤ 2.5s（移动 4G 模拟）、Performance ≥ 95、CLS ≤ 0.05。

### 5.4 静态指标基线（构建期实测，2026-08-14 验收数据）

| 指标编号 | 指标名称 | 目标阈值 | 实测数值 | 判定结论 |
|---|---|---|---|---|
| **B1** | 公开路由 First Load JS（gzip） | ≤ 115 KB | `/`、`/docs/[slug]`: 111.3 KB；`/search`: 107.7 KB；`/sections/[slug]`: 106.2 KB | **达标** |
| **B2** | 单路由增量 JS（gzip） | ≤ 25 KB | 各路由增量 6–11 KB | **达标** |
| **B3** | 客户端 Chunk "supabase" 扫描 | 0 | 全 chunk 扫描零泄漏 | **达标** |
| **B4–B6** | LCP / Lighthouse / CLS | ≤2.5s / ≥95 / ≤0.05 | 待 5.3 真实浏览器补测 | **待测** |
| **B7** | ISR / 缓存头配置 | `revalidate=3600` / `s-maxage=86400` | 板块/文档页 `revalidate=3600`，搜索索引静态化带 1 年过期 | **达标** |
| **B8** | 首屏 API 请求 | 0 | 纯静态预渲染，首屏零 `/api/*` 请求 | **达标** |
