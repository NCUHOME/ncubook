# 此间 - 知识库与技术文档索引

此间（NCU Book）是面向南昌大学学生的 AI 知识产品。平台使用 Notion 作为编辑真源，通过 Supabase 提供纯静态（SSG + ISR）极速阅读与可溯源问答。

## 代码库文档架构

- **产品规范** (`docs/product/`)：产品愿景、信息架构、内容发布流程、Notion 撰写规范与 AI 问答可溯源契约。
- **设计规范** (`docs/design/`)：设计令牌 (Design Tokens)、Lucide 图标使用标准与移动端组件契约 (Component Contracts)。
- **运维手册** (`docs/operations/`)：生产部署、EdgeOne 边缘节点配置、限流策略与紧急回滚操作指南。
- **阶段规范** (`docs/specs/`)：重构与上线版本的需求明细、设计文档、任务拆解与人类批准记录。
