# 南昌大学“香樟助学”资助育人项目文件归档

本项目入选南昌大学 2026 年度“香樟助学”校级重点育人项目（重点项目）。为推动资助工作由“保障型资助”向“发展型育人”延伸拓展，团队以南大家园工作室勤工助学技术骨干为主体，研发落地了面向全校近万名新生的校园百科与 AI 知识库产品——《香樟助航 智伴校园》（线上运行平台：[book.ncuos.com](https://book.ncuos.com)）。
