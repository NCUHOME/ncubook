# 此间 - 内容发布与数据契约

> [!IMPORTANT]
> 本文档定义了“此间”（NCU Book）在 Notion 内容源同步、格式解析、编辑约定、网页嵌入白名单、资源镜像策略以及 Supabase 存储发布时的完整技术规范与数据 Schema 契约。

---

## 1. 内容发布架构与规则

Notion 是内容编辑源；公开站是独立、可访问、可检索的发布端。同步目标是保留内容的结构与语义。

```text
Notion 页面树与富块 (Editor Source)
        │
        ▼  (publish-notion.ts 同步器)
站内 Page / Block-Tree / Asset / Anchor 数据
        │
        ▼  (ArticleRenderer 富内容渲染)
公开文章页  ├─► 关键词索引
            └─► AI 检索切片 (b-<blockId>)
```

### 1.1 必须保留的内容语义
- 页面树、标题层级、段落、列表、引用、强调色和链接。
- 表格、图片、图片组、分栏（Columns）、文件和外部嵌入。
- Notion 内部页面链接，在发布后转换为站内路由。
- 页面、标题和可引用段落的稳定锚点（`b-<blockId>`）。
- 来源、更新时间、适用校区和风险级别等可供 AI 使用的元数据。

### 1.2 发布端约束与安全白名单
- **资源托管**：图片和附件必须下载镜像上传至 Supabase 站内 Bucket (`published-content`)，严禁直接暴露出 Notion 临时签名 URL。
- **外部嵌入白名单 (Allowlist)**：网页嵌入不是可同步资源。第一版仅允许 `https://school-map.ncuos.com/`，其余网页嵌入统一降级为标题、原链接和“在外部页面打开”的外链块。
- **自适应排版**：多栏（Columns）在宽屏并列、手机端自然纵向堆叠；表格在手机端支持横向滚动并固定表头。提示块（Callout）仅保留提示语义，克制为阅读注释样式，禁止卡片化正文。
- **失败容错**：未知块、资源下载失败、内部链接无目标或数据校验失败时，该页面本次发布失败。单页失败继续提供该页最近一次成功版本；首次发布失败的页面不进入导航、搜索或 AI 索引。
- **第三方与飞书集成扩展**：支持通过 `/api/sync/lark` 进行飞书多维表格 (Bitable) 信息的定时同步与批量 Upsert，并提供与学生反馈入口绑定的飞书问卷 (Lark Form) 存根拓展。

## 2. Notion 页面树写作与编辑约定

### 2.1 页面树与 slug 规则
- 同步器只读取 `NOTION_ROOT_PAGE_ID` 指定的根页面及其后代。
- 根页面的直接子页面发布为站内板块首页；更深层子页面发布为文档页面树。
- Notion 页面 UUID 是 `Page.id`，父页面 UUID 是 `Page.parentId`。标题或位置变化不得改变身份 UUID。
- `slug` 首次发布时生成并持久化，后续修改标题或移动位置不得改变网址。

### 2.2 支持的内容块映射表

| Notion 内容 | 站内发布块 (Publish Block) | 渲染与处理规则 |
|---|---|---|
| 普通正文、引用 | `paragraph`、`quote` | 保留粗体/斜体/下划线/删除线/代码与链接 |
| 一级至三级标题 | `heading` | 生成 `b-<Notion block UUID>` 稳定锚点 |
| 无序、有序及嵌套列表 | `bulleted-list`、`numbered-list` | 保持列表层级与嵌套关系 |
| 提示块 (Callout) | `callout` | 按内容风险映射为 `info`、`warning` 或 `risk` 样式；支持子块递归 |
| 分隔线 | `divider` | 正文中的低干扰水平分隔线 |
| 表格 | `table` | 保持行列格式，手机支持横滚 |
| 图片、文件 | `image`、`file` | 镜像上传站内 Bucket，保存校验和 `Asset.publicUrl` |
| 分栏 | `columns` | 手机端按从左到右顺序纵向堆叠 |
| 子页面、页面提及 | `page-link` | 自动解析为站内内部路由 |
| 校园地图嵌入 | `embed(provider="school-map")` | 渲染 `school-map` 允许插件 |
| 书签、普通外链 | 外链标记 | 保留原 URL 与题注 |

### 2.3 资源限制与元数据配置
- **资源文件上限**：单个资源上限 50 MiB；ZIP、旧版 Word 与 OOXML 办公附件保留正文显示名，并使用 ASCII 安全存储键镜像。
- **大图处理**：大图在阅读器中延迟加载并异步解码，避免阻塞文章首屏。
- **页面元数据**：`school` 第一阶段固定为 `ncu`；`sourceUrls`、`campus`、`audiences`、`topics` 与 `riskLevel` 由同步配置按页面 ID 覆盖；未配置时默认使用 `riskLevel="normal"`。

## 3. 完整 TypeScript 数据与 Schema 契约

> [!NOTE]
> 代码库对应 Schema 文件位于 [`lib/content/published-schema.ts`](file:///c:/chengxu/ncubook/lib/content/published-schema.ts)，Supabase 数据库类型定义文件位于 [`lib/database.types.ts`](file:///c:/chengxu/ncubook/lib/database.types.ts)。

```ts
export type RichTextSpan = {
  text: string;
  annotations?: {
    bold?: boolean;
    italic?: boolean;
    strikethrough?: boolean;
    underline?: boolean;
    code?: boolean;
    color?: string;
  };
  href?: string;
  pageId?: string;
};

export type TableRow = {
  id: string;
  cells: RichTextSpan[][];
};

export type Column = {
  id: string;
  blocks: PublishedBlock[];
};

export type ListItem = {
  id: string;
  richText: RichTextSpan[];
  children?: PublishedBlock[];
};

export type PublishedBlock =
  | { type: "paragraph"; id: string; richText: RichTextSpan[] }
  | { type: "heading"; id: string; level: 1 | 2 | 3; richText: RichTextSpan[] }
  | { type: "bulleted-list"; id: string; items: ListItem[] }
  | { type: "numbered-list"; id: string; items: ListItem[] }
  | { type: "quote"; id: string; richText: RichTextSpan[]; children?: PublishedBlock[] }
  | { type: "callout"; id: string; sentiment: "info" | "warning" | "risk"; richText: RichTextSpan[]; children?: PublishedBlock[] }
  | { type: "table"; id: string; hasHeader: boolean; rows: TableRow[] }
  | { type: "columns"; id: string; columns: Column[] }
  | { type: "image"; id: string; assetId: string; caption?: string }
  | { type: "file"; id: string; assetId: string; fileName: string; sizeBytes?: number }
  | { type: "divider"; id: string }
  | { type: "page-link"; id: string; targetPageId: string; title: string };

export type PublishedPage = {
  id: string;
  slug: string;
  title: string;
  sectionId: string;
  parentId?: string;
  order: number;
  blocks: PublishedBlock[];
  updatedAt: string;
  school: "ncu";
  riskLevel: "normal" | "warning" | "sensitive";
};

export type PublishedSection = {
  id: string;
  title: string;
  slug: string;
  order: number;
};

export type PublishedAsset = {
  id: string;
  publicUrl: string;
  mimeType: string;
  sizeBytes?: number;
  sha256?: string;
};

export type PublishedContentPointer = {
  contentVersion: string;
  publishedAt: string;
};

export type PublishedFixture = {
  contentVersion: string;
  publishedAt: string;
  sections: PublishedSection[];
  pages: PublishedPage[];
  assets: PublishedAsset[];
};
```

## 4. 校验与发布更新触发

只有当完整版本通过交叉链接、资源、搜索锚点与 Schema 校验后，才触发更新 Supabase 中的 `published_content_pointer`，使学生端获得增量物理刷新（ISR）。
